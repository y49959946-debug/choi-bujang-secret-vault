# 실측 증거 파일

12단계 「1~11단계 실측표」에서 내려받은 JSON(`step12-live-<날짜>.json`)을 이 폴더에 둡니다.

- 배포 API에 실제로 보낸 요청의 상태 코드·오류 코드, 응답 머리글 `x-vercel-id`(요청 ID)·`Date`(서버 시각), 기대값과 판정만 담습니다.
- 토큰·메모 본문·전체 ID는 들어 있지 않습니다(요청 모양은 자리 표시, 시험용 기기는 ID 앞 8자리).
- 파일을 고치지 않고 내려받은 그대로 커밋합니다. 실행하지 않은 줄은 `미실행`으로 남아 있어야 합니다.

| 파일 | 실행 | 결과 |
|---|---|---|
| `step12-live-2026-10-15.json` | 커밋 `de685c9` 배포, 09:59~10:01 KST, 시험 계정 A만(남의 메모 없음) | 35/41줄 실행 · 통과 35 · 실패 0 · 미실행 6 |
| `step12-live-2026-10-15-full.json` | 커밋 `de685c9` 배포, 10:10~10:12 KST, 시험 계정 A + 남의 메모(시험 계정 B) | 41/41줄 실행 · 통과 41 · 실패 0 (SHA-256 `defc53ee9de1fe048b6979eee21f084bafd63a7f6a378044d59bc20c503ad3ad`) |

같은 날 두 번 내려받아 이름이 겹치므로 두 번째 파일은 `-full`을 붙여 저장했습니다(내용은 내려받은 그대로).
